"He" অথবা "She" ব্যবহার করে কোনো মানুষের অবস্থা, অনুভূতি বা গুণ (State / Adjectives) বোঝানোর জন্য "is" ব্যবহার করতে হয়।
নিচে আপনার জন্য প্রাত্যহিক জীবনে ব্যবহৃত ৩০টি চমৎকার অনুভূতি ও অবস্থামূলক বাক্য আপনার প্রিয় ফরম্যাটে সাজিয়ে দেওয়া হলো:

😊 ইতিবাচক অনুভূতি ও অবস্থা (Positive Feelings & States)

• He/She is happy. (সে খুশি।)
👉 Happy (হ্যাপি) — সুখী / খুশি
• He/She is good. (সে ভালো।)
👉 Good (গুড) — ভালো
• He/She is fine. (সে ঠিক আছে / ভালো আছে।)
👉 Fine (ফাইন) — চমৎকার / ভালো
• He/She is great. (সে খুব ভালো আছে।)
👉 Great (গ্রেট) — দারুণ / খুব ভালো
• He/She is excited. (সে আনন্দিত / উত্তেজিত।)
👉 Excited (এক্সাইটেড) — আনন্দিত / উত্তেজিত
• He/She is proud. (সে গর্বিত।)
👉 Proud (প্রাউড) — গর্বিত
• He/She is safe. (সে নিরাপদ।)
👉 Safe (সেইф) — নিরাপদ
• He/She is sure. (সে নিশ্চিত।)
👉 Sure (শিওর) — নিশ্চিত
• He/She is ready. (সে প্রস্তুত।)
👉 Ready (রেডি) — প্রস্তুত
• He/She is lucky. (সে ভাগ্যবান।)
👉 Lucky (লাকি) — ভাগ্যবান

😔 নেতিবাচক বা খারাপ অনুভূতি (Negative Feelings)

• He/She is sad. (তার মন খারাপ।)
👉 Sad (স্যাড) — দুঃখিত / মন খারাপ
• He/She is angry. (সে রাগান্বিত।)
👉 Angry (অ্যাংগ্রি) — রাগান্বিত / রাগ
• He/She is scared. (সে ভীত / ভয় পেয়েছে।)
👉 Scared (স্কেয়ার্ড) — ভীত / ভয় পাওয়া
• He/She is hurt. (সে কষ্ট পেয়েছে।)
👉 Hurt (হার্ট) — আঘাতপ্রাপ্ত / মনে কষ্ট পাওয়া
• He/She is jealous. (সে ঈর্ষান্বিত।)
👉 Jealous (জেলাস) — ঈর্ষান্বিত / হিংসা করা
• He/She is bored. (তার একঘেয়ে লাগছে।)
👉 Bored (বোর্ড) — বিরক্ত / একঘেয়েমি লাগা
• He/She is lonely. (সে একাকী বোধ করছে।)
👉 Lonely (লোনলি) — একাকী / একা

😴 শারীরিক অবস্থা (Physical States)

• He/She is tired. (সে ক্লান্ত।)
👉 Tired (টায়ার্ড) — ক্লান্ত
• He/She is sleepy. (তার ঘুম পাচ্ছে।)
👉 Sleepy (স্লিপি) — ঘুম ঘুম ভাব
• He/She is sick. (সে অসুস্থ।)
👉 Sick (সিক) — অসুস্থ
• He/She is weak. (সে দুর্বল।)
👉 Weak (উইক) — দুর্বল
• He/She is thirsty. (সে তৃষ্ণার্ত।)
👉 Thirsty (থার্স্টি) — তৃষ্ণার্ত
• He/She is busy. (সে ব্যস্ত।)
👉 Busy (বিজি) — ব্যস্ত
• He/She is hungry. (সে ক্ষুধার্ত।)
👉 Hungry (হাংরি) — ক্ষুধার্ত

🧠 মানসিক অবস্থা (Mental States)

• He/She is surprised. (সে অবাক হয়েছে।)
👉 Surprised (সারপ্রাইজড) — আশ্বর্যান্বিত / অবাক
• He/She is shocked. (সে धक्का খেয়েছে / মর্মাহত।)
👉 Shocked (শক্ট) — মর্মাহত / বড় ধাক্কা পাওয়া
• He/She is nervous. (সে ঘাবড়ে গেছে।)
👉 Nervous (নার্ভাস) — ঘাবড়ে যাওয়া
• He/She is worried. (সে চিন্তিত।)
👉 Worried (ওয়ারিড) — চিন্তিত
• He/She is calm. (সে শান্ত।)
👉 Calm (কাম) — শান্ত
• He/She is serious. (সে গম্ভীর / গুরুতর।)
👉 Serious (সিরিয়াস) — গম্ভীর / গুরুতর
